# Dissertation appendix implementation

`appendix_main.py` preserves the implementation supplied with the dissertation appendix for provenance. Its experimental logic is retained as supplied in the ZIP archive. The extracted standalone script was missing its import block; the imports were restored from the matching script in `Computing_Project_JR_Appendix.zip` so the preserved copy reflects that supplied version. This restoration does not validate the experiment or its reported results.

Known implementation and evaluation caveats are documented in [`../docs/reproducibility.md`](../docs/reproducibility.md). Use the refactored package for future controlled reproduction work; do not treat its outputs as historical results.
